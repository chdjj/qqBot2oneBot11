还没有监听。添加 HTTP / SSE / WebSocket 任一模式，让 OneBot 客户端接入。

五种模式

HTTP 服务器
适配器监听端口，客户端调用 POST / 发动作，事件以 POST 推送到你填的上报地址。
HTTP + SSE
动作走 POST /，事件走 GET /_events 的 SSE 流。
HTTP 客户端
事件 POST 到你填写的 HTTP 地址，适配器不监听端口。
WS 服务器
正向 WebSocket：客户端连 ws://host:port/，同一条连接收发动作与事件。
WS 客户端
反向 WebSocket：适配器主动连接你填写的 ws:// 地址，带 X-Self-ID 与 X-Client-Role: Universal。

已知的群

还没有记录到任何群 openid。它不是 QQ 群号，只能从事件里获得：

  1. 确认机器人在群里，并在「官方机器人」页显示「已连接」。
  2. 在群里 @ 机器人 发送任意一句话，openid 会自动出现在这里。
  3. 或者把机器人重新拉进群，入群事件也会记录。
  4. 已知 openid 时，用右上角「手动添加 openid」直接粘贴。

openid 与群号的区别

QQ 群号（如 1075750473）由用户可见、可直接搜群，但官方机器人接口无法用它发消息。openid 形如 A1B2C3D4E5F6A7B8，与具体机器人绑定：同一个群换了机器人就是另一套 openid。

为什么群 ID 是数字

OneBot 的 group_id 是整数。适配器为每个 QQ 群 openid 维护一个稳定的数字 ID，插件用数字即可，适配器在发送时自动换回 openid。若 openid 本身是纯数字，则直接使用它。

主动消息频控

每个群每天最多收到 1000 条机器人主动消息，未认证企业约 30 条/分钟。被动回复（收到消息后 5 分钟内回复）不受此限，适配器会优先使用被动回复。

发送一条主动测试消息

这里要填的是群 openid，不是 QQ 群号。openid 只在机器人收到该群消息后才会出现。

如何获取群 openid

QQ 官方不提供「列出机器人所在群」的接口，openid 与机器人绑定，只能从事件里拿到。按顺序试：

  1. 确认机器人已在群里，且控制台显示「已连接」。
  2. 在群里 @ 机器人 发送任意一句话 —— openid 会自动记录到「群与 openid」页。
  3. 或者把机器人重新拉进群，入群事件同样会记录 openid。
  4. 仍然拿不到时，在「群与 openid」页点「手动添加 openid」粘贴。

注意

QQ 群号（如 1075750473）不是 openid，填进去会返回 11255 请求的资源不存在。openid 形如 A1B2C3D4E5F6A7B8，并且换一个机器人就是另一套 openid。

主动消息失败怎么办

错误码 40034102 表示当前没有主动消息权限。可让群成员先 @ 机器人互动，再试；或确认机器人认证状态与频控额度。
